# 렉시컬 스코프와 동적 스코프

### 먼저 스코프란

스코프는 **변수에 접근할 수 있는 범위** 를 말한다.

```js
const globalValue = "전역";

function print() {
  const localValue = "지역";

  console.log(globalValue); // 접근 가능
  console.log(localValue); // 접근 가능
}

console.log(localValue); // ReferenceError
```

`localValue` 는 `print` 함수 내부에서만 접근할 수 있다.

## 1. 렉시컬 스코프 (Lexical Scope)

렉시컬 스코프는 **함수가 어디에서 정의됐는지** 를 기준으로 변수의 유효 범위를 결정하는 방식이다.

자바스크립트는 **렉시컬 스코프** 를 사용한다.

```js
const value = "전역";

function outer() {
  const vale = "outer";

  function inner() {
    console.log(value);
  }

  inner();
}

outer(); // "outer"
```

`inner` 함수는 `outer` 함수 안에서 정의됐다.

따라서 `inner` 내부에서 `value`를 찾을 때:

```
inner 함수 내부
    ↓ 없으면
outer 함수 내부
    ↓ 없으면
전역
```
