# 프로토타입과 생성자 함수

## 한 줄 정의

생성자 함수로 생성된 객체의 `[[Prototype]]` 은 생성자 함수의 `prototype` 프로퍼티가 가리키는 객체로 설정된다.

> **`[[Prototype]]` 은 객체의 프로토타입을 가리키는 참조 링크이다.**

## 1. 함수도 객체다.

자바스크립트에서 함수는 호출할 수 있는 **함수 객체** 이다.
따라서 일반 객체처럼 프로퍼티를 가질 수 있다.

```js
function Vehicle(type) {
  this.type = type;
}
```

`Vehicle` 은 함수이면서 객체이므로, 다음과 같은 프로퍼티를 가진다.

```js
Vehicle.name;
Vehicle.length;
Vehicle.prototype;
```

이 중 `prototype` 은 **일반 함수를 생성하면 자동으로 만들어지는 특별한 프로퍼티이다.**

```js
console.log(Vehicle.prototype);
// { constructor: Vehicle }
```

> ⚠️ 정확히 말하면 모든 함수가 `prototype`을 가지는 것은 아니다.
> 화살표 함수처럼 생성자 함수로 사용할 수 없는 함수에는 `prototype` 이 없다.

```js
const arr = () => {};

console.log(arr.prototype);
// undefined
```

이 노트에서는 `function` 키워드로 선언하여 `new`와 함께 사용할 수 있는 일반 함수를 기준으로 설명한다.

## 2. 일반 함수에서는 `prototype`을 사용할 일이 거의 없다.

일반 함수는 **특정 작업을 실행하기 위해 호출**한다.

```js
function add(a, b) {
  return a + b;
}

add(1, 2);
```

이처럼 단순히 함수를 호출할 때는 함수의 `prototype` 프로퍼티가 사용되지 않는다.

```
add(1, 2)
→ 함수 실행
→ add.prototype은 사용되지 않음
```

하지만 함수를 `new`와 함께 호출하여 **생성자 함수** 로 사용하면 `prototype` 이 특별한 역할을 한다.

```js
const vehicle = new Vehicle("Car");
```

## 3. `prototype` 과 `[[Prototype]]` 은 서로 다르다.

프로토타입을 이해하려면 다음 두 가지를 반드시 구분해야한다.

- **함수의 prototype 프로퍼티**
- **객체의 [[Prototype]] 내부 슬롯**

이름은 비슷하지만 서로 다른 개념이다.

### 함수의 `prototype` 프로퍼티

`prototype` 은 함수 객체가 가지고 있는 **일반적인 프로퍼티** 이다.

```js
function Vehicle() {}

console.log(Vehicle.prototype);
```

구조는 다음과 같다.

```
Vehicle 함수 객체
└─ prototype 프로퍼티 → 객체
```

```js
typeof Vehicle.prototype;
// "object"
```

`prototype` 프로퍼티 자체가 다른 객체의 프로토타입을 가리키는 내부 연결은 아니다.
다만 `new`로 객체를 만들 때 특별하게 사용될 객체를 보관한다.

### 객체의 `[[Prototype]]`

`[[Prototype]]` 은 객체가 자신의 부모 역할을 하는 다른 객체를 가리키는 **내부 참조 링크** 이다.

```js
const vehicle = {};
```

구조는 다음과 같다.

```
vehicle 객체
└─ [[Prototype]] → Object.prototype
```

객체에서 프로퍼티나 메서드를 찾지 못하면 `[[Prototype]]` 이 가리키는 객체에서 다시 찾는다.

`[[Prototype]]`은 내부 슬롯이므로 일반 프로퍼티처럼 직접 접근하는 값은 아니다. 다음 방법으로 확인할 수 있다.

```js
Object.getPrototypeOf(vehicle);
```

책에서는 이해를 위해 `__proto__` 를 사용하기도 한다.

## 4. 두 개념의 차이

| 구분      | `prototype`                        | `[[Prototype]]`                  |
| --------- | ---------------------------------- | -------------------------------- |
| 존재 위치 | 생성자 함수로 사용할 수 있는 함수  | 모든 객체                        |
| 종류      | 일반 프로퍼티                      | 내부 슬롯                        |
| 역할      | 생성될 객체가 상속받을 객체를 보관 | 실제로 다른 객체를 참조          |
| 접근 예시 | `Vehicle.prototype`                | `Object.getPrototypeOf(vehicle)` |

핵심은 다음과 같다.

> 함수의 `prototype` 은 단순히 객체를 값으로 가진 프로퍼티이다.
> 객체의 `[[Prototype]]` 은 실제 프로토타입 객체를 가리키는 내부 참조 링크이다.

## 5. `new` 를 사용하면 두 개념이 연결된다.

다음 생성자 함수를 살펴보자.

```js
function Vehicle(type) {
  this.type = type;
}
```

함수가 만들어질 때 `Vehicle` 에는 `prototype` 프로퍼티가 자동으로 생성된다.

```
Vehicle 함수
└─ prototype → Vehicle.prototype 객체
```

아직 `Vehicle` 을 일반 함수로만 호출하면 이 객체는 특별히 사용되지 않는다.

그러나 `new` 와 함께 호출하면 상황이 달라진다.

```js
const vehicle = new Vehicle("Car");
```

`new Vehicle()` 은 새로운 객체를 만들고, 새 객체의 `[[Prototype]]` 이 `Vehicle.prototype`을 가리키도록 연결한다.

```
Vehicle 함수
    │
    │ prototype 프로퍼티
    ▼
Vehicle.prototype 객체
    ▲
    │ [[Prototype]]
    │
vehicle 객체
```

따라서 다음 비교가 성립한다.

```js
Object.getPrototypeOf(vehicle) === Vehicle.prototype; // true

vehicle.__proto__ === Vehicle.prototype; // true
```

주의할 점은 `Vehicle.prototype` 과 `vehicle.[[Prototype]]` 이 같은 종류라는 뜻은 아니라는 것이다.

- **Vehicle.prototype**
  - 함수의 프로퍼티에 저장된 객체
- **vehicle.[[Prototype]]**
  - 그 객체를 가리키는 내부 참조 링크

두 값이 같은 객체를 가지도록 `new`가 연결해 준 것이다.

## 6. `new Vehicle()` 의 실행 흐름

```js
function Vehicle(type) {
  this.type = type;
}

const vehicle = new Vehicle("Car");
```

`new Vehicle("Car")` 이 실행되면 개념적으로 다음 과정이 실행된다.

#### 1단계: 빈 객체 생성

```js
const vehicle = {};
```

새로운 객체가 만들어진다.

#### 2단계: 프로토타입 연결

새 객체의 `[[Prototype]]` 이 생성자 함수의 `prototype` 객체를 가리키게 된다.

```
vehicle.[[Prototype]] → Vehicle.prototype
```

#### 3단계: 생성자 함수 실행

생성자 함수 내부의 `this`가 새로 만들어진 객체를 가리킨다.

```js
this.type = type;
```

따라서 다음 프로퍼티가 만들어진다.

```js
vehicle.type = "Car";
```

#### 4단계: 생성된 객체 반환

최종적으로 다음 구조를 가진 `vehicle` 객체가 반환된다.

```
vehicle
├─ type: "Car"
└─ [[Prototype]] → Vehicle.prototype
```

## 7. `constructor` 프로퍼티

일반 함수의 `prototype` 객체에는 기본적으로 `constructor` 프로퍼티가 존재한다.

```js
function Vehicle() {}

console.log(Vehicle.prototype.constructor === Vehicle);
// true
```

`constructor`는 해당 `prototype` 객체와 연결된 생성자 함수를 가리킨다.

```
Vehicle 함수
    │
    │ prototype
    ▼
Vehicle.prototype 객체
    │
    │ constructor
    ▼
Vehicle 함수
```

즉, 서로를 참조한다.

```
Vehicle
└─ prototype → Vehicle.prototype

Vehicle.prototype
└─ constructor → Vehicle
```

`vehicle` 에서도 `constructor`를 사용할 수 있다.

```js
const vehicle = new Vehicle();

console.log(vehicle.constructor === Vehicle);
```

하지만 `vehicle`이 `constructor` 프로퍼티를 직접 가지고 있는 것은 아니다.

```
vehicle에서 constructor 검색
        ↓ 없음

vehicle.[[Prototype]]으로 이동
        ↓

Vehicle.prototype에서 constructor 검색
        ↓ 있음

Vehicle 반환
```

즉, `Vehicle.prototype.constructor`를 상속받아 사용하는 것이다.

## 8. 생성자 함수의 `prototype`에 메서드 추가하기

생성자 함수의 `prototype` 객체에 메서드를 추가할 수 있다.

```js
function Vehicle(type) {
  this.type = type;
}

Vehicle.prototype.stop = function () {
  console.log("stop!");
};

const vehicle = new Vehicle("Car");

vehicle.stop();
```

`stop` 은 `vehicle` 객체에 직접 들어 있지 않다.

```
vehicle
├─ type: "Car"
└─ [[Prototype]]
      ↓
Vehicle.prototype
├─ constructor: Vehicle
└─ stop: function
```

`vehicle.stop()` 을 호출하면 다음 순서로 프로퍼티를 찾는다.

1. vehicle 객체에서 stop을 찾는다.
2. vehicle 에는 stop이 없다.
3. [[Prototype]] 이 가르키는 Vehicle.prototype으로 이동한다.
4. Vehicle.prototype에서 stop을 찾는다.
5. stop 메서드를 실행한다.

이런 검색 과정을 **프로토타입 체인 탐색** 이라고 한다.

## 핵심 정리

```
Vehicle 함수
├─ prototype ──────────────┐
└─ [[Prototype]]           │
                           ▼
                  Vehicle.prototype
                  ├─ constructor → Vehicle
                  ├─ stop()
                  └─ [[Prototype]]
                           ↓
                    Object.prototype
                           ↓
                          null

vehicle
├─ type: "Car"
└─ [[Prototype]] → Vehicle.prototype
```

```
일반 함수 생성
    ↓
함수에 prototype 프로퍼티가 만들어짐
    ↓
일반 호출에서는 거의 사용하지 않음
    ↓
new와 함께 생성자 함수로 호출
    ↓
새 객체 생성
    ↓
새 객체의 [[Prototype]]이
생성자 함수의 prototype 객체를 가리킴
    ↓
생성된 객체가 prototype의 메서드를 상속하여 사용
```
