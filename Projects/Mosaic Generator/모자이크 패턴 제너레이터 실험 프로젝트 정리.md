# 모자이크 패턴 제너레이터 실험 프로젝트 정리

참고:
https://www.instagram.com/p/DO_WskECGxW?img_index=3

## 1. 프로젝트 개요

이미지 또는 영상을 입력하면, 원본을 일정한 그리드로 나눈 뒤 각 칸의 밝기값을 분석해 색상과 크기가 다른 도형으로 다시 표현하는 **파라메트릭 비주얼 제너레이터**를 구현한다.

> **파라메트릭 비주얼 제너레이터란?**
>
> 사용자가 설정한 매개변수(Parameter)와 수학적 알고리즘을 기반으로 이미지, 3D 모델, 그래픽 등을 시각적 결과물을 자동으로 생성하는 도구이다.
>
> 처음부터 고정된 형태를 직접 그리는 방식과 달리, 크기, 개수, 곡률 색상 등 변수(값)만 바꾸면 디자인 전체가 실시간으로 자동으로 업데이트되는 것이 가장 큰 특징이다.

쉽게 말하면 이미지나 영상을 네모난 칸으로 잘게 나누고, 각 칸이 얼마나 밝은지에따라 다른 색상과 크기의 블록을 배치하는 모자이크 필터이다.
아스키 아트 제너레이터와 기본 원리는 비슷하다. 아스키 아트는 밝기에 따라 문자를 배치하지만, 이 프로젝트는 문자 대신 컬러 블록이나 도형을 배치한다.

## 2. 기본 처리 방식

1. 사용자가 이미지 또는 영상을 입력한다.
2. 입력된 소스 위에 가로·세로 그리드를 겹친다.
3. 각 그리드 칸에 해당하는 원본 이미지의 픽셀 밝기를 측정한다.
4. 측정한 밝기값을 여러 구간으로 나눈다.
5. 각 밝기 구간에 지정된 색상과 크기를 적용한다.
6. 계산된 결과를 블록이나 도형으로 화면에 그린다.

예를 들면 다음과 같다.

- 아주 어두운 영역
  - 파란색, 너비 20%
- 조금 어두운 영역
  - 파란색, 너비 40%
- 중간 영역
  - 초록색, 너비 60%
- 밝은 영역
  - 오렌지색, 너비 80%
- 아주 밝은 영역
  - 오렌지색, 너비 100%
    같은 색상을 사용하는 구간이어도 블록의 너비나 높이를 다르게 적용할 수 있다.

## 3. 주요 개념

### 소스 푸티지

변환의 기준이 되는 원본 이미지나 영상을 의미한다.

### 그리드

원본을 분석하기 위해 화면을 나누는 칸이다.

예를 들어 갈 30칸, 세로 20칸으로 나누면 총 600개의 칸이 만들어진다.

### 파라메트릭 컨트롤

사용자가 슬라이더나 색상 선택 도구를 조절하면 결과물의 형태가 즉시 바뀌는 기능이다.

## 4. 기본 기능 요구사항

### 입력 가능

- 이미지 파일 입력
- 영상 파일 입력
- 초기 실험에서는 이미지 입력을 우선 구현
- 영상은 이미지 버전이 안정된 후 확장 가능

### 그리드 기능

- 가로 칸 수 조절
- 세로 칸 수 조절
- 칸 수가 적으면 크고 단순한 패턴
- 칸 수가 많으면 촘촘하고 세밀한 패턴

### 루마값 분석

- 각 그리드 칸에 대응하는 픽셀 또는 영역의 밝기값 측정
- 측정된 값을 여러 구간으로 분류
- 구간별로 다른 시각적 속성 적용

### 도형 렌더링

- 기본 도형은 직사각형 커럴 블록
- 각 구간에 따라 블록의 색상과 크기를 다르게 적용
- 블록은 그리드 셀 내부에서 중앙 정렬하는 방식이 적절해 보임

### 표시 모드

- **width 모드:** 밝기값에 따라 블록의 가로 길이가 달라짐
- **Height 모드:** 밝기값에 따라 블록의 세로 길이가 달라짐
- 사용자가 두 모드를 전환할 수 있어야 함

## 5. UI에서 조절해야 할 항목

확실하게 요구된 항목은 다음과 같다.

- 그리드 가로 칸 수
- 그리드 세로 칸 수
- 밝기 구간별 색상
- 밝기 구간별 블록 너비 배율
- Width 모드와 Height 모드 전환

추가로 실제 사용성을 고려해 필요할 수 있는 항목은 다음과 같다.

- 이미지 또는 영상 업로드
- 초기 설정으로 되돌리기
- 원본과 결과물 비교
- 영상 재생 및 일시정지
- 구간별 설정값 확인
- 전체 결과 미리보기
- 결과 이미지 저장
- 기본 프리셋 제공

추가 UI는 실제로 구현하고, 사용해보면서 정하는 단계가 필요하다.

## 6. 열어둬야 할 확장성

### 밝기 구간 커스텀

현재는 밝기 구간을 고정된 개수로 나눌 수 있지만, 추후에는 사용자가 직접 다음 값을 조절할 수 있어야 한다.

- 전체 구간 개수
- 각 구간의 최소 루마값
- 각 구간의 최대 루마값
- 각 구간의 색상
- 각 구간의 너비와 높이
  예를 들어 사용자가 직접 0~30, 31~80, 81~150 처럼 범위를 설정할 수 있는 구조다.

### 그리드 패턴 교체

처음에는 일반적인 가로·세로 격자로 구현한다.

추후에는 다음과 같은 패턴으로 교체 가능하도록 구조를 분리해야 한다.

- 벽돌 패턴
- 엇갈린 행 패턴
- 세로 벽돌 패턴
- 다양한 벽돌 쌓기 규칙
- 반복 타일 패턴

핵심은 일반 그리드를 코드에 고정하지 않고, 그리드 좌표를 생성하는 로직을 별도로 관리하는 것이다.

### 시각 요소 확장

처음에는 컬러 직사각형 블록을 사용한다.

추후에는 각 구간별로 다음 요소를 사용할 수 있또록 확장 가능해야 한다.

- 원
- 마름모
- 선
- 타원
- 커스텀 도형
- 이미지 또는 아이콘

또한 다음 속성을 추가할 수 있다.

- width
- height
- 회전
- 투명도
- 테두리
- 모서리 둥굴기
- 위치 오프셋

## 7. 1차 구현 범위

처음부터 모든 확장 기능을 구현하면 범위가 지나치게 커질 수 있다.

1차 실험에는 다음 정도가 적절하다.

- 이미지 파일 얿로드
- 기본 직사각형 그리드
- 각 셀의 루마값 측정
- 고정된 밝기 구간 사용
- 구간별 색상 설정
- 구간별 블록 너비 설정
- Width 모드와 Height 모드
- 가로·세로 칸 수 조절
- 설정값 변경 시 결과 즉시 반영

영상, 벽돌 패턴, 구간 추가·삭제, 다양한 도형은 1차 결과를 확인한 뒤 추가하는 것이 안전하다.

## 8. 이후 확장 기능

- 영상 파일 실시간 처리
- 웹캠 입력
- 밝기 구간 개수 추가·삭제
- 각 구간의 루마 범위 직접 설정
- 벽돌 형태의 그리드
- 원과 마름모 등 다른 도형
- 결과 이미지 다운로드
- 고해상도 출력
- 설정값 저장
- 프리셋 저장 및 불러오기
- 브랜드별 스타일 프리셋
